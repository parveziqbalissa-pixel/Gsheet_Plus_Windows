# Gsheet_Plus for Windows

Windows companion to the Gsheet_Plus Android app. Sign in with Google, see All / Mine / Shared with me, open a sheet and view it as a table. Stage 1 is read-only.

Build: Actions -> "Build Windows app" -> Run workflow. Add two repository secrets first: GSP_CLIENT_ID and GSP_CLIENT_SECRET (the Google "Desktop app" OAuth client).
