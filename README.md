# Gsheet_Plus for Windows

## New in v0.8

- Saved views per table (View menu): save search, filters, sort and grouping by name.
- Colour rules: colour a row or cell automatically ("Status equals Done", "Due is before {today}").
- Cards view and a full row page (open from a card, the calendar, or the row number menu).
- Report / PDF: printable page with your letterhead and logo (Settings), saved as PDF from the browser.
- Chart and summary: bar, pie or line chart of any column, with sum/average/min/max or counts.
- New column types: Rating (stars) and Signature (draw with the mouse). Address cells open Google Maps (Ctrl+click).
- Calendar view (any Date column) and a Map of addresses (opens in the browser).
- Templates for new tables (Expenses, Inventory, Customers, Attendance, Student marks, Rent, Tasks, Medicines).
- Quick add from the tray icon; drag files from Explorer onto a selected Picture/File cell.
- Daily backups with restore, a Bin for deleted tables, and an optional PIN lock.


Windows companion to the Gsheet_Plus Android app. Sign in with Google, see All / Mine / Shared with me, open a sheet and view it as a table. Stage 1 is read-only.

Build: Actions -> "Build Windows app" -> Run workflow. Add two repository secrets first: GSP_CLIENT_ID and GSP_CLIENT_SECRET (the Google "Desktop app" OAuth client).
